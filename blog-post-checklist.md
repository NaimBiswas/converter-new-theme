# Blog Post Publishing Checklist

Use this checklist for every blog post before and after publishing.

## 1. Content

- [ ] Clear, specific H1 title
- [ ] Introduction explains the problem
- [ ] Quick answer / summary
- [ ] Table of contents for longer articles
- [ ] Logical H2 → H3 heading structure
- [ ] Short, readable paragraphs
- [ ] Useful examples
- [ ] Step-by-step instructions where applicable
- [ ] Lists where appropriate
- [ ] Comparison table where useful
- [ ] Code examples for technical topics
- [ ] Screenshots/images where useful
- [ ] Common problems / troubleshooting
- [ ] FAQ section
- [ ] Clear conclusion
- [ ] Related articles

## 2. SEO

- [ ] Primary keyword identified
- [ ] Keyword naturally included in H1
- [ ] Keyword appears naturally in introduction
- [ ] Keyword included in relevant H2/H3 headings
- [ ] SEO title written
- [ ] Meta description written
- [ ] Clean, readable URL/slug
- [ ] Canonical URL
- [ ] Internal links to relevant pages
- [ ] Internal links from existing articles
- [ ] External links to authoritative sources when useful
- [ ] Image alt text
- [ ] Article included in sitemap
- [ ] No keyword stuffing
- [ ] No duplicate/thin content

## 3. Technical HTML

- [ ] Only one H1
- [ ] Proper H2 / H3 hierarchy
- [ ] Tables use `<thead>` and `<th>`
- [ ] Images have `alt`
- [ ] Images have width/height
- [ ] Images are optimized/compressed
- [ ] Links have descriptive anchor text
- [ ] Code blocks use appropriate syntax highlighting
- [ ] Mobile responsive
- [ ] Fast page load
- [ ] No broken links
- [ ] No unnecessary JavaScript

## 4. Structured Data

- [ ] Article / BlogPosting schema
- [ ] Author information
- [ ] Published date
- [ ] Updated date, if applicable
- [ ] Featured image
- [ ] Breadcrumb schema
- [ ] FAQ schema only when the FAQ is visible and eligible

## 5. Metadata Converter Specific

- [ ] Relevant Metadata Converter tool linked
- [ ] Clear "Try the tool" CTA
- [ ] Input example
- [ ] Output example
- [ ] Supported formats mentioned
- [ ] Privacy/local-processing information where applicable
- [ ] Related converter tools linked
- [ ] Related educational articles linked
- [ ] Conversion-specific edge cases covered
- [ ] No unnecessary generic SEO filler

## 6. Before Publishing

- [ ] Read the entire article once
- [ ] Check spelling and grammar
- [ ] Verify every technical example
- [ ] Verify code actually works
- [ ] Verify table data
- [ ] Test every internal link
- [ ] Test converter/tool CTA
- [ ] Check mobile layout
- [ ] Check page speed
- [ ] Check title and meta description
- [ ] Check canonical URL
- [ ] Check structured data
- [ ] Check for broken links
- [ ] Submit/update sitemap
- [ ] Request indexing if appropriate
- [ ] Add the article to relevant category/tag

## 7. After Publishing

- [ ] Add internal links from older relevant articles
- [ ] Share on relevant communities
- [ ] Monitor impressions
- [ ] Monitor clicks and CTR
- [ ] Monitor ranking keywords
- [ ] Monitor conversions/tool usage
- [ ] Update the article when information changes

## Minimum Publishing Standard

Before publishing, make sure these are complete:

- [ ] H1
- [ ] Introduction
- [ ] Useful, original content
- [ ] Examples
- [ ] Proper heading structure
- [ ] Internal links
- [ ] Tool CTA
- [ ] SEO title
- [ ] Meta description
- [ ] Canonical URL
- [ ] Images and alt text
- [ ] Structured data
- [ ] Mobile check
- [ ] Broken-link check
